# 地下城二：永不下课的学园

基于“地下城一”核心循环制作的学校主题 Discord Roguelike。它作为主Bot的 `school_dungeon` 模块运行，使用独立数据库 `data/school_dungeon.db`，不会读取或修改地下城一的存档。

## 初版玩法

- 保留探索、随机事件、战斗、资源管理、Boss与百层远征结构。
- 全部100层分为体育、音乐美术、生物、地理、历史、化学、物理、英语、语文、数学十个区域。
- 每层拥有3种专属普通怪物，共300个不跨层重复的普通怪物名称。
- 每层固定使用一张独立场景图，共100张；同一科目的十层保持统一美术体系，但教室、色彩、道具与危险迹象逐层变化。
- 普通怪不出题；小Boss在半血时出题1次；十层大Boss出题2次；第100层最终Boss出题3次。
- Boss题目为四选一，限时10秒。答对造成Boss最大生命12%的知识伤害并打断攻击；答错或超时，Boss追加攻击一次。
- 初版题库共80道，覆盖十个科目。每位玩家保存最近100个题号，同一科目有新题时不会重复，答案按钮每次重新排列。
- 旅行商人固定为 **ego**。
- 第100层最终Boss固定为 **塞纳河畔的春水**，别名 **期末考试**。

## 本地启动

1. 安装 Python 3.11 或更高版本。
2. 安装依赖：`pip install -r requirements.txt`。
3. 在主项目目录将 `.env.example` 复制为 `.env`，填写Bot配置。
4. 在主项目目录运行 `python bot.py`。
5. 从地下城酒馆点击“探索”，选择“地下城二｜永不下课的学园”。

## 当前初版边界

- 沿用地下城一的装备、经济、商店、每日任务、每周排行和百层周目数值，后续再进行学校主题数值复盘。
- 当前题库是可运行的初版规模，正式开放前应继续扩充并逐题校对。
- 100层场景图按 `assets/floors/floor-001.webp` 至 `floor-100.webp` 独立存放；入口图使用 `assets/school-entrance.png`。
